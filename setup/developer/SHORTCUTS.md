# Shortcuts

## Claude

| Keys | What it does |
| --- | --- |
| `Enter` | Send |
| `Shift + Enter` | New line |
| `Esc` | Stop Claude |
| `Esc` `Esc` | Go back to an earlier message (on an empty prompt) |
| `Shift + Tab` | Switch mode: auto, ask first, accept edits, plan |
| `Option + P` | Switch model (use the **left** Option key) |
| `Ctrl + V` | Paste a screenshot |
| `@` | Mention a file |
| `/` | See commands |
| `/clear` | Start a new conversation: one topic per conversation |
| `/rewind` | Undo Claude's changes back to an earlier message |
| `/context` | How full this conversation is |
| `/usage` | How much of my plan is left |
| `/effort` | How hard Claude thinks: higher is smarter but uses more of my plan |
| `!` | Run a terminal command yourself, e.g. `! git status` |

## VS Code

| Keys | What it does |
| --- | --- |
| `Cmd + P` | Open a file by name |
| `Cmd + S` | Save (VS Code also saves on its own) |
| `Cmd + Z` | Undo |
| `Cmd + F` | Find |
| `Cmd + Shift + F` | Find in all files |
| `Cmd + B` | Show / hide the file list |
| `Cmd + Shift + V` | Preview a `.md` file |
| `Cmd + Shift + P` | Search every VS Code action |
| `Option + Cmd + C` | Copy a file's path (or right click on file then "Copy Path") |

## Ghostty

| Keys | What it does |
| --- | --- |
| `Cmd + T` | New tab |
| `Cmd + D` | Split the window right |
| `Cmd + Shift + D` | Split the window down |
| `Cmd + W` | Close tab / split |
| `Cmd + K` | Clear the screen |
| `Ctrl + C` | Stop what's running |

## Mac

| Keys | What it does |
| --- | --- |
| `Cmd + Space` | Search / open any app |
| `Cmd + Ctrl + Shift + 4` | Screenshot an area to the clipboard, to paste into Claude |
| `Option + Cmd + C` | Copy a file's path (in Finder) |
| `Cmd + Q` | Quit an app |
